run-owned path; do not reuse a shared or pre-existing checkout.

```bash
set -euo pipefail

TAG=v0.2.7
EXPECTED_SHA256=7095a462d42d5f44342d11c2887d7e3487f47a9e5da6efb5bb9786dae4df0518
CHECKOUT="$PAPERCLIP_RUN_SCRATCH_DIR/model-router-${TAG}-${PAPERCLIP_RUN_ID}"

test ! -e "$CHECKOUT"
id
stat -c 'uid=%u gid=%g mode=%a path=%n' \
  "$PAPERCLIP_WORKSPACE_CWD" "$PAPERCLIP_RUN_SCRATCH_DIR"

# This contacts the operation broker and prints the effective least-privilege
# repository scope without printing a credential.
node /paperclip/.local/bin/gh-app-token.js scope

git -C "$PAPERCLIP_RUN_SCRATCH_DIR" init "$(basename "$CHECKOUT")"
git -C "$CHECKOUT" remote add origin "$PAPERCLIP_WORKSPACE_REPO_URL"

# Fresh network fetch is mandatory. Do not replace this with a local tag or a
# pre-existing checkout.
GIT_TRACE=1 git -C "$CHECKOUT" fetch --force --prune origin \
  "refs/tags/${TAG}:refs/tags/${TAG}"
git -C "$CHECKOUT" checkout --detach "$TAG"

test "$(git -C "$CHECKOUT" rev-parse HEAD)" = \
  "$(git -C "$CHECKOUT" rev-parse "${TAG}^{}")"
test -z "$(git -C "$CHECKOUT" status --porcelain=v1)"

# Agent containers currently set NODE_ENV=production. Plain `npm ci` therefore
# omits the build-time dev dependencies needed by check:pin. Include them
# explicitly; do not disable the build gate.
npm --prefix "$CHECKOUT" ci --include=dev

cd "$CHECKOUT"
npm run check:pin -- --tag v0.2.7 --expect-sha256 7095a462d42d5f44342d11c2887d7e3487f47a9e5da6efb5bb9786dae4df0518
```

The final command above is deliberately literal. Do not add `--offline`,
`--no-build`, or any other bypass.

## Failure classification and control flow

| Observation | Classification | Required action |
|---|---|---|
| Broker returns `409 Issue run ownership conflict` | Broker refusal / issue lease unavailable | Record the holder or checkout run from the issue, stop, and retry only in a new run after that lease releases. Do not bypass the helper or use a cached local ref. |
| Issue is not `in_progress` | Broker precondition failure | Correct the issue status only if its blockers are actually resolved; otherwise stop with the blocker and owner named. |
| `git fetch` fails before the tag is fetched | Substrate/network/auth failure | Stop. A local tag is not acceptable evidence. Retry only after the broker, network, or repository scope is restored. |
| Fetched tag commit differs from the recorded pin, or package/changelog gates fail | Stale or inconsistent pin | Stop. Return to release ownership; do not install and do not rewrite the runbook around the mismatch. |
| `git diff v0.2.7..HEAD -- src` is non-empty | Unexpected source drift | Stop and cut/accept a new release through the release owner. Do not install v0.2.7. |
| Plain `npm ci` installs only production dependencies and build reports missing `esbuild` | Reversible local dependency-environment failure | Confirm `NODE_ENV=production`, rerun `npm ci --include=dev`, then rerun the same exact `check:pin` command. Do not use `--no-build`. |
| Any `FAIL`, any `SKIP`, or non-zero exit from `check:pin` | Pin/policy/artifact verification failure | Stop. No operator handoff is valid. Offline checks and skipped gates are not acceptable. |
| Any policy test/build comparison fails | Policy or artifact mismatch | Stop and route back to Model Router release ownership. Never disable the failing check. |
| A requested next step mutates outside Model Router Plugin/Ops Tooling | Scope violation | Stop and reassign the mutation to its owning project/agent. |
| Plugin install, company configuration, release/tag creation, or runtime mutation is proposed during this preflight | Out of scope | Do not perform it. The preflight ends at the handoff below. |
